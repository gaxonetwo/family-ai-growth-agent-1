# configs/ 配置目录

存放项目运行配置。目前包含：

- `settings.yaml`：项目名称、统一统计时区、数据截止日期、默认数据规模、随机种子，以及原始数据、处理数据、ground truth 和 SQLite 数据库路径。
- `privacy`：合成数据使用要求，以及禁止纳入儿童个人信息、语音、视频和聊天内容等约束。

## 使用说明

- 数据截止日期等配置会影响日期解析和分析窗口，修改前应确认是否会改变现有分析口径。
- 路径配置应与实际数据目录保持一致。
- 不要在配置文件中写入 DeepSeek API Key 或其他秘密信息；密钥应通过环境变量提供。
- 修改配置后，应运行相关日期解析和数据路径测试。

本目录只保存配置，不存放业务分析代码或运行数据。
