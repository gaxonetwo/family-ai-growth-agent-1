# scripts/ 项目脚本目录

本目录存放从项目根目录执行的辅助脚本。目前包含：

- `run_phase1.py`：串联第一阶段数据流水线，依次执行合成数据生成、数据质量校验和 SQLite 导入。

## 运行方式

在确认需要初始化或重建本地合成数据后，从项目根目录执行：

```powershell
python scripts/run_phase1.py
```

该脚本会生成数据并导入本地数据库，可能覆盖已有运行数据。**未经用户明确授权，不要运行该脚本**；已有本地数据时也不要为了验证项目而重复生成。

数据处理的具体实现位于 `src/data/`。本目录提供流程入口，不承载业务指标计算、Agent 决策或数据库查询逻辑。
