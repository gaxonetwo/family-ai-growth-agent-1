# reports/ 分析报告输出目录

本目录预留给项目运行过程中生成的分析报告和导出结果。

当前仓库仅保留目录占位文件；这不代表已经实现报告持久化、报告管理页面或 Web 界面。

## 使用约定

- 报告应来自真实工具执行结果，并保留指标口径、数据范围、统计限制和证据来源。
- Fake/Mock 测试报告必须明确标记为测试结果，不得冒充正式业务分析。
- 不要把 API Key、个人信息、原始数据库或不必要的明细数据写入报告。
- 报告文件属于运行产物，默认不提交到 Git；如需版本化某份示例报告，应先确认其为安全的合成数据，并单独评估是否适合提交。

报告生成和证据校验逻辑位于 `src/agent/result_explainer.py` 与 `src/agent/report_semantics.py`；本目录只负责报告文件的输出位置。
