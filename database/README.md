# database/ 数据库结构目录

本目录存放 SQLite 数据库的结构定义。目前包含：

- `schema.sql`：创建项目使用的业务表、字段约束、外键和查询索引。

## 当前业务表

| 表 | 内容 |
|---|---|
| `users` | 用户注册时间、获客渠道、地区和当前套餐 |
| `devices` | 设备类型、绑定时间、当前状态和最近在线时间 |
| `events` | 用户行为事件及事件时间 |
| `feedback` | 用户反馈时间、渠道和反馈文本 |
| `payments` | 支付时间、金额、套餐和支付状态 |

## 与运行数据库的区别

- `database/schema.sql` 是可版本管理的结构脚本。
- 本地运行数据库位于配置指定的 `data/processed/family_ai.db`，不应提交到 Git。
- Agent 不直接访问任意数据库路径；业务查询通过受只读模式、表白名单和查询限制约束的 SQL 查询工具执行。
- `data/ground_truth/` 不属于 Agent 的业务查询数据源。

修改表结构前，先检查四个业务分析模块、SQL 查询工具和测试中的字段依赖，并取得必要确认。数据库结构变更应配套测试，不要在普通测试中修改正式数据库。
