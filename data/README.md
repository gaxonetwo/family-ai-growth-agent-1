# data/ 合成业务数据目录

本项目使用合成的 Family AI 用户、设备、行为事件、反馈和支付数据进行业务分析与 Agent 验收。数据不代表真实公司或真实用户。

## 子目录

| 目录 | 用途 | 使用边界 |
|---|---|---|
| `raw/` | 原始合成业务 CSV | 作为数据流水线输入；本地数据文件由 Git 忽略规则管理 |
| `processed/` | 处理后的数据及 SQLite 数据库（如 `family_ai.db`） | 业务工具通过只读查询接口访问；数据库文件不提交到仓库 |
| `ground_truth/` | 离线评估参考数据 | 仅供离线评估使用，Agent 和业务分析工具不得读取 |

## 数据安全与维护

- 当前 GitHub 目录可能只显示 `.gitkeep` 占位文件；本地运行后生成的 CSV 和数据库文件不会自动出现在仓库中。
- 不要为了补齐目录而上传本地数据库、CSV、ground truth 或真实用户数据。
- 不要在未获用户明确授权时运行数据生成、覆盖、删除、迁移或重新导入操作。
- 测试应使用临时数据库和独立测试数据，不得修改正式本地数据。
- 修改数据结构前，先检查 `database/schema.sql` 及现有业务工具依赖。

数据生成、校验和导入代码位于 `src/data/`；本目录只负责存放数据文件。
